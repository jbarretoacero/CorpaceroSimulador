# Simulador Corpacero — Android

Aplicación móvil Android `Simulador_V3.xlsx` (Simulador de Pesos para Productos Transformados de
Corpacero).

## Descarga

[Descargar Simulador Corpacero v1.0.7 (APK)](https://github.com/jbarretoacero/CorpaceroSimulador/releases/download/v1.0.7/CorpaceroSimulador-v1.0.7.apk)

> En Android, abrir la APK descargada y permitir "Instalar de fuentes
> desconocidas" para el navegador / gestor de archivos cuando lo solicite.

> **Actualizando desde v1.0.6:** desinstalar primero la versión anterior
> antes de instalar v1.0.7. La firma del APK cambió, por lo que Android
> no permite la actualización directa sobre la instalación anterior.
